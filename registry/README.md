# Реестр агентов, проектов и задач

Единый источник правды для дашборда, агентов и приёма задач. Файлы правятся и человеком, и агентами.

## Файлы

| Файл | Кто пишет | Что внутри |
|---|---|---|
| `agents.yaml` | вы / Lead | Агенты: id, имя, роль, модель, `enabled` (тумблер в дашборде), статус, проекты, группы, расписание, входы/выходы |
| `projects.yaml` | вы / Lead | Проекты (наши ЖК) и агенты, которые их ведут |
| `prices.yaml` | агент (T11) | Цены моделей за 1 млн токенов + курс валюты — для расчёта расхода в рублях |
| `tasks/<YYYY-MM>.yaml` | агент приёма задач | Задачи: группа → категория → задача, исполнитель, статус, проект |
| `intake/` | вы | Входящее: аудио из Телемоста, транскрипты, заметки |

## Схема задачи

```yaml
- id: T-12
  subject: "Проверить новую акцию у Селигер Сити"
  group: "Конкуренты"
  category: "Акции"
  owner: agent-1-competitor-watch
  status: new          # new | in_progress | done | blocked | unassigned
  project: my-zhk-svet
  due: "2026-11-05"
  source: telemost-voice   # telemost-voice | telemost-text | manual | agent
  created: "2026-10-31"
  quote: "фрагмент транскрипта, из которого взялась задача"
```

Поля `group` и `category` задают вложенность в дашборде: группа — крупный блок («Конкуренты», «Директ», «Креативы», «Аналитика»), категория — подблок внутри группы. Задачи без понятного владельца помечаются `status: unassigned` и попадают в раздел «требует уточнения» — их разбирает человек.

## Как добавить нового агента

1. Добавьте блок в `agents.yaml` (id — латиница с дефисами, уникальный).
2. Укажите `enabled: true` и модель.
3. Добавьте группы в `groups`, чтобы задачи правильно раскладывались по дереву.
4. Перезапустите сборщик дашборда — карточка агента появится в интерфейсе.

## Важно

- Задачи не выдумываются: если формулировка неоднозначная, агент помечает её `unassigned` и выносит в «требует уточнения».
- Расход в рублях считается только для моделей, у которых есть цена в `prices.yaml`; для остальных в интерфейсе честно показывается «цена неизвестна».
