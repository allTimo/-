# Панель управления (dashboard)

Веб-панель «Центр управления агентами» — единая точка контроля: какие агенты включены,
что они сделали, сколько это стоило и на каких данных построены цифры.

**Запуск локально:**

```powershell
node dashboard/serve.mjs                 # http://127.0.0.1:8787
$env:DASHBOARD_PORT=8788; node dashboard/serve.mjs   # другой порт
```

**Как устроена панель:**

```
registry/*.yaml                 ← ЕДИНЫЙ ИСТОЧНИК ПРАВДЫ (агенты, цены, проекты, задачи)
        ↓
dashboard/collector/collect.mjs ← сборщик: читает реестр + сессии DSH + логи
        ↓
dashboard/public/data/*.json    ← машиночитаемый снимок состояния
        ↓
dashboard/serve.mjs             ← локальный сервер + API /api/state
        ↓
dashboard/public/*              ← интерфейс: index.html, app.js, sidebar.js, styles.css
```

**Ключевые свойства:**

| Свойство | Где реализовано |
|---|---|
| Тумблер вкл/выкл агента — **единственная запись** за пределами `dashboard/` | `dashboard/serve.mjs` (атомарно + `.bak`-копия) |
| Доступ по ключу при публикации наружу | `dashboard/config/access.key` (в репозиторий не входит) |
| Меню строится из одного файла | `dashboard/config/nav.yaml` |
| Связь «агент реестра ↔ исполнитель DSH» | `dashboard/config/links.yaml` |
| Полные карточки интеграций | `dashboard/config/integrations-full.yaml` |
| Автотест поведения интерфейса (заморожен) | `dashboard/ux-check.mjs` → `dashboard/ux-report.json` |
| Проверка целостности данных | `dashboard/verify-data.mjs` |
| Приёмка одной командой | `install/check-dashboard.ps1` |

## Агент 1: мониторинг конкурентов

**Что даёт:** раз в неделю — отчёт об изменениях цен на лоты, новых акциях и количестве лотов в продаже у конкурентов.

**Как устроен цикл:**

```
inbox/ (скриншоты, выгрузки, ссылки)
      ↓   агент нормализует данные
data/snapshots/<дата>/lots.csv      ← снимок предложения на дату
      ↓   diff_snapshots.py
reports/.cache/diff-<дата>.json     ← машиночитаемые изменения
      ↓   build_weekly_report.py
reports/<дата>-competitor-watch.md  ← отчёт для человека
reports/<дата>-competitor-watch.xlsx
```

**Что автоматизировано:** нормализация, проверка схемы, сравнение недель, расчёт медиан и Δ%, сборка отчёта Markdown + Excel, короткая сводка для Telegram.

**Что делает человек:** кладёт входные данные в `inbox/` (Циан и Авито закрыты антиботом — прямой парсинг не используется), проверяет отчёт и принимает решения по кампаниям.

**Отчёт состоит из 9 разделов:** охват → главное за неделю → медианы ₽/м² → изменения цен по лотам → акции → предложение и приход/уход → срез по комнатности → выводы и рекомендации → ограничения.

## Скилы и плагины

Подход: **стандартные скилы и готовые плагины из маркета DSH**, без самописных скилов под недвижимость.

- Встроенные скилы доступны сразу: `office`, `office-xlsx`, `office-docx`, `office-pptx`, `office-render`, `office-export-pdf`, `office-recalculate`, `dsh-badge`, `adversarial-review`, `diagnose-windows-sandbox-acl`.
- Из маркета установлены маркетинговые плагины и скилы — список, требования к ключам и откат описаны в `install/README-market-plugins.md`.
- Собственные скилы (`skills/`) сняты с установки и лежат черновиками.
- После установки плагинов нужен **полный перезапуск DSH** (закрыть приложение, включая значок в трее).

## Самопроверка: три команды

```powershell
$py = "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
$node = "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe"

# 1) плагин и скилы на месте
& $node --test marketing-agents\tests\plugin-contract.test.mjs

# 2) движок считает правильно (47 тестов)
& $py -m unittest discover -s marketing-agents\01-competitor-watch\tests

# 3) ваши конфиги заполнены верно
& $py marketing-agents\00-admin\scripts\validate_config.py
```

Все три должны завершиться без ошибок. Если третий ругается — он пишет, в каком файле и какое поле поправить.

## Как запустить проверку вручную

Через ассистента: «Загрузи скил competitor-watch и собери недельный отчёт по конкурентам за эту неделю».

Вручную (если нужно без агента):

```powershell
$py = "$env:USERPROFILE\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py marketing-agents\01-competitor-watch\scripts\snapshot_tool.py validate 2026-10-30
& $py marketing-agents\01-competitor-watch\scripts\diff_snapshots.py --prev 2026-10-23 --curr 2026-10-30
& $py marketing-agents\01-competitor-watch\scripts\build_weekly_report.py --curr 2026-10-30 --prev 2026-10-23 --telegram
```

## Принципы контроля

- Никаких выдуманных цифр: чего нет в источнике — остаётся пустым и попадает в раздел «Ограничения».
- Каждое изменение в отчёте прослеживается до строки снимка.
- Снимки не перезаписываются: история недель сохраняется, её можно пересчитать.
- Конфиги — ваши: агент читает их, но не меняет.
