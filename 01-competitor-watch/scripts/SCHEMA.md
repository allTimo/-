# SCHEMA.md — контракт входного снимка (зафиксирован Lead, менять нельзя)

## Файл

- Путь: marketing-agents/01-competitor-watch/data/snapshots/<YYYY-MM-DD>/lots.csv
- Кодировка: UTF-8. Для Excel файлы пишутся как UTF-8 с BOM (utf-8-sig); чтение принимает оба варианта.
- Разделитель: запятая. Перенос строки: CRLF.
- Одна строка = один лот в предложении конкурента на дату снимка.
- Файл создаётся командой: snapshot_tool.py new <YYYY-MM-DD>

## Колонки: строго в этом порядке

| № | Колонка | Тип | Обяз. | Допустимые значения / правило |
| --- | --- | --- | --- | --- |
| 1 | snapshot_date | дата | да | YYYY-MM-DD; должна совпадать с датой папки снимка |
| 2 | source | строка | да | cian, avito, yandex_realty, site, other (data_contract.enums.source) |
| 3 | competitor | строка | да | застройщик/продавец, например СЗ Гранель |
| 4 | project | строка | да | название ЖК, например Селигер Сити |
| 5 | lot_id | строка | да | стабильный id лота; если у источника нет id — хэш ссылки (lot_id_fallback) |
| 6 | url | строка | нет | http:// или https:// |
| 7 | rooms | целое | да | 0 = студия, 1–5, 6 = 5 и более. Диапазон 0..6 |
| 8 | area_m2 | число | да | 10..400 м², разделитель — точка (запятая тоже принимается) |
| 9 | floor | целое | нет | этаж, целое число |
| 10 | floors_total | целое | нет | этажей в доме; floor не может быть больше |
| 11 | building | строка | нет | корпус/секция |
| 12 | price_rub | число | да | цена лота в рублях, строго больше 1 000 000 |
| 13 | price_per_m2_rub | число | нет | если пусто — движок досчитывает price_rub / area_m2 |
| 14 | finish | строка | да | без отделки, white box, чистовая, с мебелью, unknown |
| 15 | promo_flag | целое | да | 0 или 1; 1 только вместе с непустым promo_text, 0 — только с пустым |
| 16 | promo_text | строка | нет | дословная формулировка акции; при promo_flag=1 обязательна |
| 17 | delivery | строка | нет | YYYY-QN, например 2027-Q2 |
| 18 | status | строка | да | active, reserved, sold |

Порядок колонок проверяется буквально: перестановка колонок — ошибка валидации.

## Ключ сопоставления лота

(source, competitor, project, lot_id)

- Ключ должен быть уникален внутри снимка: дубль — ошибка валидации.
- Лот считается одним и тем же между неделями только при полном совпадении ключа.
  Переименование проекта или смена lot_id выглядит как «уход + приход» — это осознанное поведение.
- Изменения цен считаются по этому же ключу (в отчёте дополнительно печатается lot_id).

## Досчёт price_per_m2_rub

Если price_per_m2_rub пуст, normalize (и движок при чтении) считает его как price_rub / area_m2
с округлением до целых рублей. Если значение заполнено, оно проверяется на сходимость:
расхождение с price_rub / area_m2 больше 1% — ошибка валидации.

## Что проверяет validate

1. Заголовок: наличие всех 18 колонок, отсутствие лишних, точный порядок.
2. Число колонок в каждой строке.
3. Обязательные поля не пусты.
4. Форматы: snapshot_date (YYYY-MM-DD), delivery (YYYY-QN), url (http/https).
5. Диапазоны: rooms 0..6, area_m2 10..400, price_rub > 1 000 000.
6. Словари: source, finish, status, promo_flag.
7. Согласованность: floor <= floors_total, promo_flag и promo_text, price_per_m2_rub.
8. Дубли по ключу (source, competitor, project, lot_id).
9. Наличие хотя бы одной строки с данными.

Формат сообщения об ошибке: «строка N: проблема» (N — номер строки в файле, заголовок = строка 1).

## Коды возврата CLI

| Код | Значение |
| --- | --- |
| 0 | успех, ошибок валидации нет |
| 1 | найдены ошибки валидации или операция отклонена (файл уже существует) |
| 2 | фатальная проблема входа: файл не найден, пустой файл, битый заголовок |

## Поведение normalize

1. Приводит типы (целые и числа), заменяет запятую на точку.
2. Досчитывает price_per_m2_rub, если пусто.
3. Отбрасывает строки с пустым ключом или непарсящимися rooms/area_m2/price_rub.
4. Убирает дубли по ключу, оставляя первое вхождение.
5. Сортирует по (snapshot_date, competitor, project, lot_id).
6. Перезаписывает файл в utf-8-sig с CRLF.
7. Печатает статистику: строк на входе, сохранено, отброшено дублей, отброшено некорректных, досчитано ₽/м².
