# inbox/ — входные данные Агента 1

Эта папка — **точка входа**. Всё, что вы собрали руками по конкурентам, кладётся сюда.
Агент 1 читает файлы отсюда, превращает их в снимок `data/snapshots/<YYYY-MM-DD>/lots.csv`
и дальше считает изменения.

> Напоминание: прямого парсинга Циан/Авито нет (антибот, капча, JS-рендер).
> Источники попадают сюда вручную — выгрузками, сохранёнными страницами и скриншотами.
> Разбор источников: [../../00-admin/research/sources-research-2026-10-30.md](../../00-admin/research/sources-research-2026-10-30.md).

---

## 1. Что можно класть в inbox

| Тип данных | Форматы | Что из него агент берёт |
|---|---|---|
| Выгрузка Циан (личный кабинет) | `.xlsx`, `.csv` | цены, площади, комнатность, этаж, статус лота |
| Скриншоты выдачи / карточек | `.png`, `.jpg`, `.jpeg` | цифры и тексты акций (распознаются/переносятся вручную) |
| Сохранённые HTML-страницы (Ctrl+S) | `.html`, `.htm`, `.mhtml` | список лотов, цены, тексты акций |
| Текстовые заметки, копипаста | `.md`, `.txt` | акции, комментарии, недостающие поля |
| Презентации/буклеты застройщика | `.pdf` | условия акций, сроки сдачи, УТП |

**Не кладите сюда:** личные фото, переписку, пароли, данные наших клиентов.
CSV с русским текстом сохраняйте в **utf-8-sig**, иначе Excel покажет кракозябры.

## 2. Схема имён файлов (обязательно)

```
<YYYY-MM-DD>_<источник>_<конкурент>.<ext>
```

- `<YYYY-MM-DD>` — дата, за которую собраны данные (не дата файла на диске).
- `<источник>` — один из: `cian`, `avito`, `yandex_realty`, `site`, `other`.
  Это те же значения, что попадают в колонку `source` снимка (см. `settings.yaml -> data_contract.enums.source`).
  Если данные не с площадки и не с сайта застройщика (заметка, буклет, отчёт ДОМ.РФ) — ставьте `other`.
- `<конкурент>` — `id` конкурента из `00-admin/config/competitors.yaml` (например, `zhk-competitor-1`).
  Использовать именно id, а не русское название: по нему агент связывает файл с карточкой конкурента.
- `<ext>` — расширение по типу файла.

Можно добавить уточнение через дефис, если файлов за один день несколько:
`<YYYY-MM-DD>_<источник>_<конкурент>-<уточнение>.<ext>`.

---

## 3. Примеры правильных имён

```
2026-10-27_cian_zhk-competitor-1.xlsx          # выгрузка Циан по «Символ» за 27.10.2026
2026-10-27_cian_zhk-competitor-1-lots.csv      # та же выгрузка, сохранена как CSV
2026-10-27_avito_zhk-competitor-3.png          # скриншот выдачи Авито по «ЗИЛАРТ»
2026-10-27_yandex_realty_zhk-competitor-2.html # сохранённая страница Яндекс Недвижимости
2026-10-27_site_zhk-competitor-4.html          # страница акций с официального сайта
2026-10-27_other_zhk-competitor-5.md           # заметки: «с 28.10 рассрочка 0% на 12 мес»
2026-10-27_other_all.md                        # сводная заметка по всем конкурентам
2026-10-27_other_all-domrf.xlsx                # контекст из открытых данных ДОМ.РФ
```

Неправильно (агент не свяжет файл с конкурентом или не поймёт дату):

```
скрин.png                    # нет даты, источника и конкурента
Символ.xlsx                  # русское название вместо id
2026.10.27_cian_simvol.xlsx  # точки вместо дефисов в дате
2026-10-27_cian_zhk-competitor-1.xlsx   # верно
```

## 4. Куда и когда складывать

- Кладите файлы **в корень** `inbox/` — подпапки не нужны и не читаются.
- Дата в имени должна попадать в недельный цикл: сбор — **понедельник**
  (см. [../../00-admin/runbook.md](../../00-admin/runbook.md)).
- Если по конкуренту на этой неделе данных нет — ничего не кладите.
  Агент напишет об этом в разделе 9 отчёта «Ограничения».
- После успешного запуска недельного цикла файлы можно убрать в архив
  (например, `inbox/archive/<YYYY-MM-DD>/`), чтобы следующая неделя была чистой.
  **Старые снимки в `data/snapshots` не удаляйте** — без них не посчитается Δ.

---

## 5. Мини-чек-лист перед запуском цикла

- [ ] Имена файлов соответствуют схеме `<YYYY-MM-DD>_<источник>_<конкурент>.<ext>`
- [ ] Источник — из набора `cian | avito | yandex_realty | site | other`
- [ ] Дата в именах — понедельник текущей недели
- [ ] В данных есть хотя бы цена и площадь (иначе не посчитать ₽/м²)
- [ ] CSV сохранён в utf-8-sig
- [ ] В `competitors.yaml` есть все id, которые использованы в именах файлов
