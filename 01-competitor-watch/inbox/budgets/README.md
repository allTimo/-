# inbox/budgets — выгрузки бюджетов из кабинетов сервисов

Сюда кладутся файлы, выгруженные из личного кабинета Keys.so / SpyWords (CSV, TSV или TXT).
Этот способ работает СРАЗУ, без токенов и настройки API.

Как использовать:
1. выгрузите отчёт из кабинета (контекстная реклама по домену конкурента);
2. положите файл в этот каталог (кодировка utf-8-sig или cp1251, разделитель ; , или tab);
3. запустите: python scripts/budget_sources.py --source csv

Колонки распознаются по смыслу: затраты/бюджет/adcost → оценка бюджета; ads/объявления → число
объявлений; ключи/keywords → число фраз; url/посадочные → уникальные посадочные; domain → домены.

Правило честности: любые суммы из этих выгрузок помечаются как «оценка сервиса», а не как
фактический расход застройщика.
