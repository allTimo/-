# Skill 4a: семантика и спрос (Яндекс.Wordstat)

## Статус (11.11.2026)

* **Wordstat не подключён.** API-доступа нет, автозапросы частотности не выполняются:
  в артефактах проекта поле `frequency` остаётся «нет данных», а не нулём.
* Что нужно для подключения: заявка на доступ к API Wordstat в том же OAuth-приложении
  (Client ID сохранён в `docs/agent2-integration-2026-11-10.md`), затем чтение отчётов по фразам.
* Пока данные собираются **вручную** (выгрузка из интерфейса Wordstat или из Директа по
  поисковым запросам) и прикладываются к работе с датой снятия.
* Похожая ситуация: **API Директа ждёт одобрения заявки (ошибка 58)** — доступно только чтение
  (`Campaigns.get`, `Reports`), Метрика работает (счётчик, цели, `stat/v1/data`).
* Аудитории не подключены; офлайн-конверсии не реализованы.

## Какой доступ нужен

| Доступ | Назначение | Состояние |
|---|---|---|
| Wordstat API (OAuth-приложение проекта) | частотность и вложенные запросы по фразам | нет |
| Регион/гео в запросе | спрос по Москве и районам, а не по РФ | нет |
| История за периоды | динамика и сезонность | нет |
| Оператор `-минус`, `"кавычки"` | точная и очищенная частотность | нет |

## Порядок работы

1. **База фраз** — из ТЗ и `direct-keywords`: ЖК, районы, метро, параметры лота
   (студия, 1–3 комнаты, отделка, ипотека, рассрочка, цена «от»).
2. **Снятие частотности** — по каждой фразе: базовая частотность + точная (в кавычках),
   регион Москва и МО, дата снятия. Нет данных — «данных нет».
3. **Оценка спроса** — разделить на ядро (высокий спрос, головные запросы), середину и
   хвост (длинные запросы с интентом на покупку); для новостроек хвост часто конверсионнее ядра.
4. **Динамика и гео** — сравнить периоды (сезонность: весна/осень), разложить по районам и метро;
   рост/падение спроса фиксировать процентами с периодом сравнения.
5. **Новые кластеры** — вложенные запросы («похожие», «что ещё ищут») дают кандидатов;
   добавлять только после проверки на мусорные интенты (аренда, вторичка, работа, отзывы).
6. **Передача в работу** — очищенные фразы и кластеры уходят в `direct-keywords`
   (структура) и `direct-campaign-management` (кампании), минус-слова — в `ppc-audit`.

## Правила

* Частотность без источника и даты не используем: «данных нет» честнее приблизительной цифры.
* Мусорные интенты отсекаем до кластеризации, а не после запуска кампаний.
* Один смысловой интент — один кластер; посадочная под кластер обязательна.
* Сезонность учитываем в медиаплане (`performance-unit-economics`), а не задним числом.
* Запись в Директ (кампании, ключи, ставки) — **только по явному подтверждению** пользователя.
* Токены — только из `marketing-agents/.env` (`YANDEX_OAUTH_TOKEN`, `YANDEX_DIRECT_CLIENT_LOGIN`,
  `YANDEX_METRICA_COUNTER_ID`); в текстах — `Bearer [СКРЫТО]`.
* Контроль баллов API (`Units`): остаток < 10 % — предупреждение.
