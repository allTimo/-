# Skill 1: юнит-экономика и медиапланирование

Порядок: сначала вводные от бизнеса, потом формулы, потом сценарии. Ни одной цифры «из головы».

## Статус (11.11.2026)

* **API Директа ждёт одобрения заявки (ошибка 58)** — доступно только чтение: `Campaigns.get`, `Reports`.
* **Метрика работает** (счётчик, цели, `stat/v1/data`); **Wordstat и Аудитории не подключены**;
  **офлайн-конверсии из CRM не реализованы** — продажи и выручка тогда честно «данных нет».
* CLI: `python -m skills.direct_api --check --json`, `--metrika-report --from/--to`.

## Шаг 1. Запросить вводные (без них не считать)

| Вводная | Обозначение | Что делать, если не дали |
|---|---|---|
| Средний чек | AOV | «данных нет», расчёт остановлен |
| Маржинальность (доля маржи в чеке) | `M`, % | «данных нет» |
| Конверсия лид → продажа | `CR_sale`, % | «данных нет» |
| LTV клиента | LTV | «данных нет» (считать только на первой сделке) |
| Конверсия клик → лид | `CR_lead`, % | «данных нет» до появления данных Метрики |
| Средняя цена клика | CPC | из `Reports` Директа, с датой |
| Бюджет на период | `B` | запросить |

Если хотя бы одна ключевая вводная не дана — **пишем «данных нет»** и показываем формулы
с подстановкой вместо выдуманных значений.

## Шаг 2. Формулы

* Маржа с продажи: `маржа = AOV × M`
* Максимальный CAC (окупаемость на первой сделке): `CAC_max = AOV × M`
* Максимальный CAC с LTV: `CAC_max = LTV × M × D`, где `D` — допустимая доля маржи на рекламу
* Целевой CPL: `CPL_target = CAC_max × CR_sale`
* Целевой ДРР: `ДРР_target = расход / выручка × 100 % ≤ M × D × 100 %`
* Прогноз лидов: `лиды = бюджет / CPL`
* Прогноз продаж: `продажи = лиды × CR_sale`
* Прогноз выручки: `выручка = продажи × AOV`
* ROMI: `ROMI = (выручка × M − расход) / расход × 100 %`

## Шаг 3. Медиаплан (цепочка)

| Этап | Формула | Данные |
|---|---|---|
| Показы | `клики / CTR` | CTR — из `Reports` Директа |
| Клики | `бюджет / CPC` | CPC — из `Reports` Директа |
| Лиды | `клики × CR_lead` | CR_lead — Метрика, цель |
| Продажи | `лиды × CR_sale` | CRM/Метрика, если доступно |
| Выручка | `продажи × AOV` | данных нет без AOV |
| ДРР | `бюджет / выручка × 100 %` | расчёт |

## Шаг 4. Три сценария

| Сценарий | Что меняем |
|---|---|
| Пессимистичный | CTR и CR ниже факта на 20 %, CPC выше на 20 % |
| Базовый | фактические показатели за последний сопоставимый период |
| Оптимистичный | после гипотез: CTR +10 %, CR +10 %, CPC на уровне факта |

По каждому сценарию: клики, лиды, продажи, выручка, ДРР, ROMI, требуемый бюджет.

## Пример расчёта (вводных нет)

```
Исходные: AOV = данных нет, M = данных нет, CR_sale = данных нет, бюджет = 300 000 ₽
CAC_max = данных нет; CPL_target = данных нет; лиды = 300 000 / CPC — CPC: данных нет
Итог: медиаплан не считается; запросить AOV, M, CR_sale, CR_lead. Сценарии не публикуем.
```

## Границы и безопасность

* Запись в Директ (кампании, ставки, бюджеты) — **только по явному подтверждению** пользователя.
* Токены — только из `marketing-agents/.env` (`YANDEX_OAUTH_TOKEN`, `YANDEX_METRICA_COUNTER_ID`,
  `YANDEX_DIRECT_CLIENT_LOGIN`); в текстах — `Bearer [СКРЫТО]`.
* У каждой цифры — источник (Директ `Reports`, Метрика `stat/v1/data`, CRM, пользователь) и дата.
* Контроль баллов API по заголовку `Units`: остаток < 10 % — предупреждать.
