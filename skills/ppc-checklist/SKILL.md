# Чек-лист аудита PPC — 105 пунктов (обязательный к применению)

Источник: формулировки пользователя, 13.11.2026. Согласовано как обязательный инструмент.

## Как применять (правило сессии)

1. **Перед ответом** по рекламе: прогнать пункты, относящиеся к теме ответа (не обязательно все 105).
2. В ответе дать строку статуса и перечень незакрытого:
   `Проверка по чек-листу: проверено N · нет данных M · не применимо K. Не закрыто: пп. … (что нужно).`
3. **Запрещено** выдавать рекомендацию по пункту, который не проверен. Если данных нет — писать «данных нет» и что именно нужно (выгрузка, доступ, интерфейс).
4. Полный прогон всех 105 — при аудите аккаунта; при операционном ответе — только релевантный раздел.
5. Каждый вывод сопровождать: источник данных + период + дата выгрузки.
6. Запись в аккаунт (минус-слова, площадки, ставки, бюджеты, стратегии) — только по явному подтверждению пользователя.

## Режимы применения по типам вопросов

| Тип вопроса | Разделы чек-листа |
|---|---|
| Юнит-экономика, ДРР, ROMI, бюджеты | 1 (экономика) + 4 (стратегии) |
| Аудит аккаунта/структуры | 2, 3, 4, 5, 6 |
| Минус-слова, семантика | 3 |
| РСЯ, площадки, ретаргетинг | 5 (+ 3 для поиска) |
| Объявления, креативы, посадочные | 6 |
| Быстрый операционный ответ | только пункты, прямо относящиеся к вопросу |

## 1. Экономика и данные — 18 параметров

2. Рассчитан Break-even CPL.

6. Задан целевой CPA по каждой кампании.
7. Задан предельный ДРР.
8. Рассчитан ROMI по направлениям.
9. Конверсии Метрики сверены с CRM.
10. Считается доля квалифицированных лидов.
11. Считается доля оплат из лидов.
12. Передаются офлайн-конверсии.
13. Подключён коллтрекинг.
14. Цели соответствуют бизнес-ценности.
15. Нет дублей и «мусорных» целей.
16. Проверена модель атрибуции.
17. Проверено окно атрибуции.
18. UTM-разметка единая и корректная.
