# Скилы: черновики (НЕ подключены)

Решение пользователя (2026-10-30): **не писать собственные скилы под недвижимость**. Сначала используем стандартный набор скилов DSH и готовые плагины/скилы из маркета; собственные скилы пишем только когда появится конкретная задача и мы отдельно разберём, какой именно скил и под что.

Статус этих файлов:

- `competitor-watch/SKILL.md`, `newbuild-ru-glossary/SKILL.md`, `direct-keywords/SKILL.md` — **черновики**. Они были установлены в DSH локальным плагином `dsh-marketing-skills`, затем установка **откатана** (`install/install-marketing-plugin.ps1 -Revert`): плагин удалён, строка из `cordis.patch.yml` профиля убрана, каталог скилов вернулся к стандартному набору.
- Рабочий регламент Агента 1 живёт не в скиле, а в документах: `00-admin/runbook.md`, `01-competitor-watch/README.md`, `01-competitor-watch/scripts/README.md`.
- Если решим вернуть скилы в работу — достаточно запустить `install/install-marketing-plugin.ps1` и перезапустить DSH.

Заменяющий подход: стандартные встроенные скилы (`office-xlsx`, `office-docx`, `dsh-badge` и др.) + плагины/скилы из маркета DSH. Список установленного — в `install/README-market-plugins.md`.
