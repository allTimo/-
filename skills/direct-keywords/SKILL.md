# Семантика и кампании для Яндекс Директа (Агент 2)

**Статус: каркас (следующий этап).** Регламент и структура зафиксированы, инструменты пока не реализованы. Когда пользователь просит «собрать семантику», «сделать кампании в Директе», «сгруппировать ключи» — этот скил задаёт порядок работы, но результат потребует ручных шагов.

## Что должен делать Агент 2

1. **Сбор семантики**: Wordstat и подсказки Яндекса, поисковые запросы по ЖК/районам/метро, параметры (студия, 1-2-3 комнатная, с отделкой, ипотека, рассрочка, цена от), бренды конкурентов и собственных ЖК, гео-модификаторы.
2. **Чистка**: минус-слова по мусорным интентам — аренда, снять, работа, вакансии, вторичка, б/у, отзывы, фото, ЖКХ, аварийный, снос, форум, ремонт, купить квартиру вторичную, обои.
3. **Лемматизация и дедупликация**: «квартира»/«квартиры»/«квартиру» — один кластер.
4. **Кластеризация по интенту**: (а) бренд нашего ЖК, (б) бренд конкурента, (в) район/метро, (г) параметры лота, (д) цена/ипотека/рассрочка, (е) общие запросы по новостройкам в Москве.
5. **Сборка кампаний**: поиск и РСЯ отдельно; группы по кластерам, единый смысловой интент на группу; посадочная страница под каждый кластер обязательна.
6. **Объявления**: заголовок 1 и 2, текст, быстрые ссылки, уточнения; укладываться в лимиты Директа; для премиума — сдержанный тон без «дёшево» и «успей».
7. **Выгрузка**: шаблон под Директ Коммандер (XLS) или API Директа, с последующей проверкой на модерации.

## Контракт ТЗ от пользователя

Агент 2 запускается только по ТЗ. Минимальный состав: ЖК/проект, класс, локация, УТП, цена входа и диапазон, срок сдачи, ссылка на посадочную, целевой регион, бюджет, ограничения по брендам, желаемые группы.

## Границы

Ключи и объявления генерируются как черновик для человека. Изменение ставок и бюджета без явного подтверждения — не выполняется. Данные об эффективности берутся из самого аккаунта Директа, а не оцениваются «на глаз».

## Что нужно для запуска следующего этапа

- Доступ к Wordstat или согласие работать через ручные выгрузки.
- Список ЖК и приоритетных кластеров (совпадает с `00-admin/config/my-objects.yaml`).
- Файл ТЗ в оговоренном формате (появится вместе с реализацией).
