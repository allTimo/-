# Начните здесь: 5 шагов

## Шаг 1. Заполните три конфига (15 минут)

1. `00-admin/config/my-objects.yaml` — ваши ЖК: название, класс, локация, срок сдачи, ссылка, УТП.
2. `00-admin/config/competitors.yaml` — конкуренты: название, застройщик, класс, локация, ссылки на Циан/Авито/Яндекс Недвижимость.
3. `00-admin/config/settings.yaml` — правила: порог значимости цены, словарь акций, формат отчёта.

В каждом файле есть примеры с пометкой «ЗАМЕНИТЕ» — просто перепишите их под себя.

## Шаг 2. Перезапустите DSH

Скилы `competitor-watch`, `newbuild-ru-glossary`, `direct-keywords` подхватываются при старте приложения. После перезапуска ассистент сможет их загружать.

## Шаг 3. Соберите первый снимок

Вариант А (рекомендую): попросите ассистента — «собери первый снимок по конкурентам за эту неделю». Он попробует открытые источники и скажет, чего не хватает.

Вариант Б: сложите в `01-competitor-watch/inbox/` то, что у вас уже есть (скриншоты выдач, выгрузки Циан в Excel, сохранённые страницы) — правила именования в `inbox/README.md`.

Первый снимок — это базовая линия: «изменений» в нём ещё нет.

## Шаг 4. Получите отчёт

Через неделю повторите сбор — ассистент сам посчитает diff и соберёт отчёт `.md` + `.xlsx` в `01-competitor-watch/reports/`.

Недельное напоминание уже настроено: каждый понедельник в 10:00 (Москва) ассистент сам предложит собрать срез. Напоминание живёт в текущей сессии DSH.

## Шаг 5. Контролируйте качество

Перед тем как использовать отчёт в работе, пройдите чек-лист из `00-admin/runbook.md` (7 пунктов). Если что-то не сходится — скажите ассистенту, он пересчитает: снимки сохранены, история не потеряна.
