# Три варианта современного дизайна сервиса

Пользователь просил предложить 3 варианта: удобные по UX, красивые, чтобы приятно было работать. Ниже — три направления. По каждому: настроение, палитра, типографика, форма, движение, где уместно.

## Вариант 1. «Пульт» — рабочий инструмент (развитие текущего)

**Настроение:** сосредоточенность, плотность, ничего лишнего. Для ежедневной работы по 8 часов.

- **Палитра:** фон `#0a0a0a` / `#121212`, поверхности `#1a1a1a` / `#222`, границы `#2e2e2e`; акцент `#7553ff`; успех `#05df72`, ошибка `#f14c4c`, инфо `#4fc1ff`.
- **Типографика:** Inter, цифры — JetBrains Mono; компактные строки (высота 1,35), таблицы плотные.
- **Форма:** радиусы 10–14 px, тонкие границы, минимум теней.
- **Движение:** почти нет — только подсветка наведения и мгновенная реакция.
- **Плюсы:** максимум данных на экране, привыкание после первого дня, глаза не устают.
- **Кому:** вам и операторам сервиса.

## Вариант 2. «Кабинет» — светлый и воздушный

**Настроение:** спокойствие, доверие, «дорого и просто». Хорошо продаёт и не пугает клиента.

- **Палитра:** фон `#f7f7f8`, поверхности `#ffffff`, границы `#e6e6e9`; текст `#111` / `#5b5b66`; акцент тот же `#7553ff`; статусы — пастельные плашки (мягкие зелёный/красный/синий).
- **Типографика:** Inter, крупные заголовки (24–32 px), значения KPI 28–36 px, много воздуха.
- **Форма:** радиусы 16–24 px, мягкие тени, карточки «плавают» над фоном.
- **Движение:** плавные появления карточек (150–200 мс), мягкие раскрытия.
- **Плюсы:** красиво, приятно, идеально для демонстраций клиенту.
- **Кому:** личный кабинет клиента, презентации, продажи.

## Вариант 3. «Стекло» — тёмный премиум с градиентами

**Настроение:** вау-эффект, ощущение современного продукта.

- **Палитра:** глубокий фон `#08080c` с мягкими градиентными пятнами (`#7553ff` → `#4fc1ff`), полупрозрачные поверхности (стекло) `rgba(255,255,255,.04)` + размытие; акцент-градиент `#7553ff → #a78bfa`; успех/ошибка — насыщенные.
- **Типографика:** Inter с крупными заголовками, цифры JetBrains Mono, лёгкое свечение у ключевых чисел.
- **Форма:** радиусы 20–28 px, тонкие светящиеся границы, стеклянные панели.
- **Движение:** аккуратные микроанимации: появление цифр, подсветка активной карточки, лёгкий параллакс градиента.
- **Плюсы:** запоминается, выглядит как продукт 2026 года.
- **Риск:** при долгой работе «стекло» и градиенты утомляют; нужно не переусердствовать.

## РЕШЕНИЕ ПОЛЬЗОВАТЕЛЯ (01.11.2026)

- **«Пульт»** — для панели оператора (рабочая панель).
- **«Кабинет»** — для личного кабинета клиента (поверхность «Клиент»).
- **«Стекло»** — для посадочной страницы (лендинг сервиса), не для рабочих экранов.
- Причина: оператор работает в панели часами → нужна плотность и спокойный фон; клиент заходит на минуту → нужна понятность и доверие; лендинг продаёт → нужен вау-эффект.

## Как выбрать

- Если сервис для **себя и операторов** — вариант 1.
- Если показываете **клиентам и продаёте** — вариант 2.
- Если нужен **вау-эффект на презентациях** — вариант 3.

Можно комбинировать: **вариант 1 для панели оператора + вариант 2 для кабинета клиента**. Это моя рекомендация как наиболее практичная.

Могу собрать все три как кликабельные макеты — посмотрите и выберете.
