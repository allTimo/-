# Промпт для старта новой сессии

Скопируйте текст из блока ниже в первое сообщение новой сессии.

## Текст промпта

```text
Проект: marketing-agents (папка marketing-agents в рабочем каталоге). Продолжаем работу после сессии 04.11.2026.

Сначала, до любой работы с кодом, прочитай:
1) marketing-agents/docs/roadmap.md — роадмап проекта по этапам;
2) marketing-agents/docs/session-start.md — состояние, карта проекта, факты среды, риски;
3) marketing-agents/docs/open-tasks-2026-11-04.md — полный перечень незакрытых задач;
4) marketing-agents/docs/working-rules.md — правила работы в проекте.

Затем покажи мне короткую сводку: что уже закрыто, что осталось (списком по приоритетам, с указанием,
что зависит от меня), и предложи, с какой задачи начать. После этого остановись и жди моего выбора —
следующую задачу сам не начинай.

Когда я назову задачу: возьми только её, работай по правилам проекта (честность данных в интерфейсе,
приёмка через node dashboard/verify-data.mjs и замороженный dashboard/ux-check.mjs; registry/** и .gh-upload/** — только чтение;
ux-check.mjs правится только через Lead). Если задача большая — собери команду и веди её, разделив зоны записи.
В конце задачи покажи: что сделано, чем проверено, что осталось — и снова остановись и жди выбора.
```

## Короткий вариант (если лень копировать длинный)

```text
marketing-agents: прочитай docs/roadmap.md, docs/session-start.md, docs/open-tasks-2026-11-04.md и docs/working-rules.md,
покажи сводку «закрыто / открыто / нужно от меня» и предложи, с чего начать. Дальше жди моего выбора.
```

## Напоминание

- Промпт не отменяет правило «остановка после каждой задачи»: Lead показывает список и ждёт решения.
- Если сессия долгая и контекст разросся — выгоднее начать новую сессию этим же промптом: состояние проекта
  сохранено в файлах выше, ничего важного в переписке не осталось.
