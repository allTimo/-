## 5. Что осталось / риски

1. **E (веб-поиск по району) не закрыт:** `discover_competitors.py` без `--search-results` или `CW_SEARCH_ENDPOINT` ищет только по каталогу Циан — районный поиск честно помечается «веб-поиск не настроен». Радиус работает по каталогу площадок.
2. **Панель на 8787 — старый процесс** (держит в памяти прежний код сборщика; из сессии этот процесс не управляется, PID виден в `netstat`, но процесс недоступен для перезапуска). Свежая сборка поднята Lead'ом на **http://127.0.0.1:8791** — посмотреть результат можно там; для привычного адреса 8787 панель нужно перезапустить (`node marketing-agents\dashboard\serve.mjs`).
3. **Журнал отправки:** на экране аналитики у получателей могут показываться причины из файлов разных дат (`email-2026-11-03.json` — «нет SMTP-доступа», `email-2026-11-04.json` — `sent`). Это доработка сборщика, к четырём пунктам не относится.
4. **Живой отправки по SMTP после новой логики не было** (и по требованию «не слать при обновлении» её быть не должно). Позитивный путь проверен подменой транспорта: `always` + `auto_send: true` + канал email → `sent` + журнал + статус в аналитике (QA). Реальная отправка людям — только сознательным действием: кнопкой в панели или плановым прогоном.
5. **Независимый разбор кода** (`review`, линзы correctness/contract) не отработал: инфраструктура инструмента упала, покрытия нет — только тесты, независимые проверки данных и замороженный ux-check.
6. `F9` (ключ лота Циан) и `D1` (профили 20 конкурентов) остаются открытыми, как и было в роадмапе.
