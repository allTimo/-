## 2. `class` — расхождение двух валидаторов (разрешено без выдумывания)

`clients.py:102-104` требует только `name`, но `00-admin\scripts\validate_config.py:43` требует **наличие** полей `name, developer, class, site, platforms`, при этом значение `class` проверяется только если оно непустое (`:292`). Следовать только `clients.py` нельзя — тогда `validate_config` даёт `ERROR: нет поля class` (воспроизведено, exit 1).

Решение: значение ставится **только из подтверждённого источника** `00-admin\config\competitors.yaml` (обновлён 2026-10-31) — это даёт `class: "бизнес"` у 7 записей (Селигер Сити, Дмитровское небо, Kinetic, Квартал МОНС, Онежский вал, Акценты, Михалковский). У остальных 13 официальных конкурентов класс в источниках не подтверждён → `class: ""` (пусто = неизвестен; значение НЕ выдумано, но поле присутствует под контракт валидатора). В шапке файла это описано; в TODO добавлен пункт «подтвердить class для 13».
