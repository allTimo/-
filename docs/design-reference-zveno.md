# Референс дизайна: zveno.ai

Пользователь выбрал https://zveno.ai как образец дизайна, UX и функционала. Скриншот: `docs/reference/zveno-ai.png`.

## 1. Палитра (взята из CSS самого сайта)

| Роль | Цвет | Где применять |
|---|---|---|
| Основной фон | `#0a0a0a` — `#171717` | Тёмная тема панели |
| Поверхности | `#1e1e1e` — `#272727` — `#3c3c3c` | Карточки, плитки, панели |
| Текст основной | `#ffffff` / `#fafafa` | Заголовки, значения |
| Текст вторичный | `#cccccc` / `#a1a1a1` / `#737373` | Подписи, пояснения |
| Границы | `#2e2e2e` / `#3c3c3c` | Рамки карточек и таблиц |
| **Акцент** | `#7553ff` (нажатие `#553db8`) | Кнопки действий, активная вкладка, ссылки |
| Успех | `#05df72` / `#00c758` | «Работает», рост, выполнено |
| Ошибка/критично | `#f14c4c` / `#ff6568` | Тревоги, падение, долг |
| Инфо | `#4fc1ff` | Подсказки, нейтральные статусы |

Правило: интерфейс почти монохромный, цвет — только для смысла.

## 2. Типографика и форма

- Шрифт — **Inter** (fallback: system-ui, -apple-system, sans-serif); цифры и суммы — **JetBrains Mono**.
- Радиусы: примерно 8 / 12 / 16 / 24 px (крупные у карточек, средние у кнопок).
- Блоки: заголовок раздела, короткое пояснение, сетка карточек.
- Кнопки: основная — акцентная заливка, второстепенные — прозрачные с рамкой.

## 3. UX-паттерны zveno.ai, которые берём

| Паттерн с их сайта | Как применяем у нас |
|---|---|
| «Расходы видны до копейки»: в кабинете видно, сколько стоит каждый день и каждая модель, в рублях | Вкладки «Расходы» и «Экономика»: те же разрезы — по дням, моделям, услугам, клиентам |
| Каталог возможностей карточками | Каталог услуг карточками: что делает агент, что получит клиент, срок, цена |
| Два входа: «в браузере» и «через API» | Два входа: «Панель оператора» и «Личный кабинет клиента» |
| «Один ключ ко всем моделям»: 3 карточки-действия | Блок «С чего начать»: подключить клиента / подключить услугу / посмотреть отчёт |
| Планы и подписки отдельным блоком | Раздел «Подписки и тарифы» со сравнением |
| Поддержка в Telegram 24/7 | «Вопрос агенту» + Telegram-канал поддержки |
| Честные формулировки об ограничениях | Наши плашки: «данные за период», «цена неизвестна», «источник не отвечает» |

## 4. Структура панели по образцу

- Шапка: логотип, переключатель поверхности (**Оператор / Клиент**), поиск, период, профиль.
- Слева — лента разделов, контент — сетка карточек.
- Плитки KPI с проваливанием: клик → список → карточка → отчёт (вариант 1, выбран пользователем).
- Один акцентный цвет, остальное монохром.

## 5. Что НЕ копируем

- Маркетинговые блоки про модели и API.
- Лендинг целиком: нам нужен кабинет, а не продающая страница.
