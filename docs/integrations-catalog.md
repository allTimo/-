# Каталог интеграций: что предлагать людям

Пользователь просил: «в Интеграции добавить все возможные интеграции — CRM, Яндекс Метрика, Яндекс Директ, ВК, все популярные рекламные каналы, системы сквозной аналитики, чтобы отдавать и передавать им данные; предложить все, где можно подключиться по API».

Для каждой записи в панели показываем: **что даёт агенту**, **направление** (читаем / пишем / оба), **способ** (OAuth, API-ключ, выгрузка файлом), **где взять доступ**, **статус**.

## A. CRM

| Интеграция | Что даёт | Направление | Способ | Где взять доступ |
|---|---|---|---|---|
| **amoCRM** | Заявки, воронка, сделки: агент видит лиды и возвращает результат работы в карточку сделки | оба | OAuth + вебхуки | Личный кабинет amoCRM → интеграции |
| **Битрикс24** | То же: лиды, сделки, задачи; запись результата в таймлайн | оба | OAuth / входящий вебхук | Настройки → Разработчикам |
| **retailCRM** | Заказы и клиенты (для смежных задач) | оба | API-ключ | Кабинет → API |
| **МойСклад** | Клиенты, заказы, счета | оба | API-ключ | Кабинет → Настройки → API |
| **YCLIENTS** | Записи/визиты (если клиент оказывает услугу офлайн) | чтение | API | Кабинет → Интеграции |
| **Универсальный вебхук** | Любая CRM, у которой нет готовой интеграции: агент шлёт результат POST-запросом | пишем | HTTP | наш URL + токен |

## H. Инфраструктура для интеграций

| Что | Зачем |
|---|---|
| **Входящие и исходящие вебхуки** | Любая система может отдать нам событие или получить результат |
| **REST API панели** | Клиент или его подрядчик забирает данные сам |
| **n8n / Make / Zapier** | Связка без кода с любыми сервисами |
| **BI-выгрузка (Metabase и др.)** | Свои дашборды поверх наших данных |

## Правило отображения в панели

Каждая запись: название · логотип-заглушка · что даёт (одна строка) · направление · способ · «где взять доступ» · **статус** (подключено / можно подключить / требует партнёрства / нет открытого API) · кнопка «Подключить» или «Как получить доступ».

Честность обязательна: если у сервиса нет открытого API (часть площадок недвижимости), так и пишем — и предлагаем выгрузку файлом.
