# Переработка панели под сервис

Документ для согласования. Дополняет предложение по MVP.

## 1. Главное изменение: две поверхности вместо одной

| Поверхность | Кому | Задачи |
|---|---|---|
| **Операторская панель** | вам | Услуги, клиенты, подписки, очередь, агенты, деньги, качество |
| **Личный кабинет клиента** | вашему заказчику | Свои услуги, объекты, отчёты, счета |

Сейчас панель — «пульт одного человека». В новой модели она становится **пультом сервиса**, а для клиента появляется отдельный, сильно упрощённый кабинет.

## 2. Новая структура операторской панели

| Вкладка | Что показывает | Ключевые действия |
|---|---|---|
| **Обзор** | Тревоги, KPI сервиса, деньги за период | Проваливание в проблему одним кликом |
| **Клиенты** | Список клиентов: тариф, услуги, статус, оплата, следующий отчёт | Добавить, пауза, продлить, сменить тариф |
| **Подписки** | Кто на каком тарифе, сроки, продления, долги | Продлить, поменять тариф, выставить счёт |
| **Услуги** | Каталог: что входит, кто исполняет, расписание, себестоимость, цена | Включить/выключить, изменить цену и состав |
| **Очередь работ** | Что запущено, что в работе, что упало, что ждёт | Запустить, повторить, остановить, посмотреть лог |
| **Агенты** | Кто чем занят, загрузка, успешность, расход | Вкл/выкл, пауза, приоритет |
| **Объекты** | ЖК и конкуренты по всем клиентам | Добавить, отредактировать, сменить владельца |
| **Экономика** | Доход, себестоимость прогонов, маржа по услуге и клиенту | Экспорт, сравнение периодов |
| **Качество** | Сроки, доля принятых отчётов, сбои, повторные прогоны | Разбор инцидентов |
| **Настройки** | Правила, пороги, модели и цены, расписания, роли | Полный контроль параметров (уже есть) |

## 3. Плитки с проваливанием — 10 вариантов

Предлагаю поддержать все, начиная с первых трёх:

1. **Клик по плитке → список** сущностей за ней (например, «12 клиентов» → список клиентов), из списка → карточка, из карточки → отчёт. Хлебные крошки и кнопка «назад».
2. **Боковая панель (выдвижная)**: детали открываются справа, не теряя текущий экран — удобно сравнивать.
3. **Раскрытие на месте**: плитка разворачивается в мини-таблицу прямо на «Обзоре».
4. **Модальное окно** с таблицей и фильтрами — когда нужно быстро посмотреть и закрыть.
5. **Переключатель группировки** прямо над плитками: по клиенту / по услуге / по агенту / по объекту / по периоду.
6. **Проваливание по времени**: неделя → день → конкретный прогон.
7. **Сравнение периодов**: в плитке сразу «+18% к прошлой неделе», клик — что именно выросло.
8. **Срез по сегменту**: все клиенты на тарифе «Бизнес», все на паузе, все с долгом.
9. **Сохранённые представления**: «мои фильтры» как закладки вверху панели.
10. **Быстрый поиск** по клиенту/объекту/задаче с переходом сразу в нужный экран.

## 4. Действия в панели: 15 кнопок

К трём базовым («собрать данные», «сформировать отчёт», «запустить агента») добавляю ещё 12:

1. **Поставить агента на паузу / снять с паузы.**
2. **Запустить услугу конкретному клиенту** (разово, вне расписания).
3. **Создать задачу вручную**: исполнитель, срок, приоритет.
4. **Повторить прогон за дату** (пересобрать данные, если источник был недоступен).
5. **Отправить отчёт клиенту**: в кабинет, в Telegram, на почту, ссылкой.
6. **Выставить счёт/акт** за период (PDF/Excel).
7. **Сменить статус клиента**: лид, активен, пауза, ушёл.
8. **Продлить или сменить подписку.**
9. **Добавить/отредактировать объект клиента** (ЖК, конкуренты, ссылки).
10. **Изменить расписание услуги** (день, время, частота).
11. **Проверить источники** (health-check площадок) и увидеть, что живёт, а что нет.
12. **Сравнить с прошлым периодом** по выбранному клиенту.
13. **Сгенерировать черновик письма клиенту** по отчёту.
14. **Стоп-кран**: остановить все долгие задачи; и наоборот — перезапустить упавшие.
15. **Экспорт** (см. раздел 5).

## 5. Экспорт: 8 вариантов

1. **Excel, многолистовой** — сводка, цены, изменения, акции, лоты (уже есть).
2. **Excel, сводный** по всем клиентам (для вас как оператора).
3. **CSV** за период — для загрузки в другие системы.
4. **PDF-отчёт для клиента** — с вашим логотипом, готовый к отправке.
5. **Markdown** — для быстрой вставки в чат или Telegram.
6. **JSON** — для интеграций и автоматизации.
7. **Ссылка на веб-отчёт** — открывается у клиента без скачивания.
8. **Пакет отчёта (ZIP)** — отчёт + исходные данные + графики, одним архивом.

## 6. Утверждённые улучшения — как они ложатся в новую модель

| Улучшение | Где окажется |
|---|---|
| Тревоги на «Обзоре» | Плюс тревоги уровня сервиса: клиент без отчёта, просроченная оплата, упавший прогон |
| Кнопки действий | Те же 15 кнопок, часть — на уровне клиента, часть — на уровне услуги |
| Задачи: создание и закрытие | Очередь работ + задачи агентов, с привязкой к клиенту и услуге |
| Мои объекты в панели | Раздел «Объекты» по всем клиентам |
| История изменений | Журнал: кто и когда менял настройки, тарифы, расписания |
| Экспорт | 8 вариантов выше |
| Плитки с проваливанием | 10 вариантов выше |

## 7. Порядок работ (предложение)

1. Согласовать MVP и структуру панели (этот документ).
2. Внедрить 7 утверждённых улучшений в текущую панель — они нужны в любом случае.
3. Добавить в панель разделы **Клиенты / Подписки / Услуги / Очередь** (без кабинета клиента).
4. Собрать **личный кабинет клиента** (упрощённый, только просмотр).
5. Пилот на 1-3 клиентах, замер экономики, затем каталог услуг и оплата.
