# Хостинг и юридическая часть (старт как самозанятый)

## 1. Рекомендуемая конфигурация

| Компонент | Что брать | Ориентир по цене |
|---|---|---|
| Сервер | VPS: 2 vCPU, 4 ГБ RAM, 60 ГБ NVMe, Ubuntu 24.04 | 500–900 ₽/мес |
| Домен | .ru или .рф | 200–900 ₽/год |
| SSL | Let's Encrypt (бесплатно, автообновление) | 0 ₽ |
| Бэкапы | ежедневные, хранение 7–14 дней | 100–300 ₽/мес |
| Хранилище отчётов | тот же диск на старте | 0–200 ₽/мес |
| **Итого на старте** | | **≈ 800–1400 ₽/мес** |

Хватает на пилот с 1–3 клиентами и 20–50 прогонов услуг в месяц.

## 3. Что должно быть на сервере

1. Веб-приложение (кабинет клиента + панель оператора) за HTTPS.
2. База данных (на старте SQLite, далее Postgres) + ежедневные бэкапы.
3. Очередь прогонов услуг и журнал выполнения.
4. Хранение артефактов (отчёты Excel/PDF, снимки).
5. Мониторинг доступности, ошибок, расхода токенов.
6. Разделение данных по клиенту — на уровне запросов и файлов.

## 4. Юридическая часть

| Что | Суть | Статус |
|---|---|---|
| Налоговый режим | НПД (422-ФЗ): 6% с юрлиц, 4% с физлиц; лимит 2,4 млн ₽/год | Стартовый вариант |
| Чеки | Каждый расчёт — чек в «Мой налог» | Обязательно |
| Сотрудники | НПД запрещает наём работников | Учитывать при росте |
| Оферта | Публичный договор: состав услуги, сроки, отказ, ответственность | До первых продаж |
| Персональные данные | Уведомление в Роскомнадзор, политика конфиденциальности, согласия | Обязательно |
| Хранение данных | Данные россиян — на серверах в РФ | Учтено выбором хостинга |
| Документы клиенту | Акт + чек; для юрлиц — счёт и закрывающие | По запросу |
| Доступы клиента | Согласие и NDA, если клиент даёт доступы к своим кабинетам | До услуг |

Готов подготовить по вашей команде: шаблон оферты, политику конфиденциальности, чек-лист РКН, шаблон акта.

## 4a. Переход на ИП (решение пользователя, 01.11.2026)

Причина: деньги клиентов проходят через платформу — при НПД это агентская деятельность, которая законом о самозанятых исключена. Поэтому регистрируется **ИП**.

| Что | Как | Зачем |
|---|---|---|
| Налоговый режим | **УСН «Доходы» 6%** (самый простой старт) | Платить с **комиссии**, а не с оборота |
| Расчётный счёт | Открыть в банке с удобным эквайрингом и СБП | Приём бюджетов и вознаграждений |
| Онлайн-касса | Нужна при расчётах с физлицами; для безнала с юрлицами — по ситуации | Чеки |
| Договоры | С оператором (агентский или на услуги) + с рекламодателем | Разделить оборот и доход |
| Учёт | Разделять **оборот**, **комиссию платформы** и **кэшбэк операторов** | Иначе налоговая база раздуется |

**Ключевое правило:** через счёт проходит чужие деньги — это не ваш доход. Доход = комиссия за сервис + подписка. Это должно быть видно в панели и в документах.

Что стоит уточнить у бухгалтера до первых платежей: схема договора с оператором (агентский или возмездные услуги), нужна ли ККТ при безналичных расчётах, как оформлять кэшбэк оператору (вознаграждение или возврат части).

## 5. Порядок переезда в интернет

1. Домен + VPS в Москве, Ubuntu.
2. Приложение + БД + бэкапы, HTTPS.
3. Первый клиент вручную: цикл «услуга → отчёт → счёт».
4. Затем открытая регистрация и оплата.
