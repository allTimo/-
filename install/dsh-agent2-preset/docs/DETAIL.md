# Агент 2 — Яндекс Директ (пресет DSH)

Режим агента для работы по Агенту 2 проекта **marketing-agents**: контекстная реклама новостроек
в Яндекс.Директе (API v5) и аналитика в Яндекс.Метрике.

## Что делает

1. Задаёт роль: цель — выручка и окупаемость (ROMI/ДРР), а не клики и CTR.
2. Требует перед задачей прочитать карту агента
   `marketing-agents/agents/agent-2-direct-semantics/SYSTEM-PROMPT.md`.
3. Требует загрузить профильные скиллы проекта инструментом `skill`, обязательный —
   `ppc-checklist` (105 пунктов) перед любой рекомендацией по рекламе.
4. Полные тексты всех десяти скиллов лежат одним файлом:
   `prompt-bundle.md` (пересборка: `python marketing-agents/tools/build_agent2_prompt_bundle.py`).

## Скиллы, которые использует пресет

`ppc-checklist`, `ppc-audit`, `direct-keywords`, `direct-campaign-management`,
`metrika-cross-analytics`, `performance-unit-economics`, `performance-ops`,
`yandex-performance-head`, `yandex-wordstat`, `yandex-audience`.

Скиллы приходят из профиля (провайдер `dsh-marketing-skills`). Если каталог скиллов пуст —
запустите установщик плагина скиллов и перезапустите DSH.

## Ограничения

* Пресет не подключает рекламный аккаунт и не хранит токены: доступы берутся из `marketing-agents/.env`.
* Запись в аккаунт (минус-слова, площадки, ставки, бюджеты, кампании) выполняется только по явному
  подтверждению пользователя; по умолчанию режим только чтение.
* Пресет не гарантирует загрузку скиллов моделью: это правило поведения. Жёсткая гарантия — только
  вместе с явным вызовом `skill`.
