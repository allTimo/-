# Как ux-check поймал дефект T73 (историческое свидетельство)

До фикса T73 переключатели «По конкурентам / По метрикам / По источникам» в «Аналитике»
подсвечивались, но ВИДИМОЕ содержимое не менялось. Структурная приёмка этого не видела,
потому что проверяла наличие элементов в DOM.

ux-check.mjs сравнивает отпечаток ВИДИМОГО текста (#view.innerText) до/после клика.
На дефектной версии два режима давали ОДИНАКОВЫЙ отпечаток:

| Прогон | По конкурентам | По метрикам | По источникам | Вердикт |
|---|---|---|---|---|
| 1-й (18:47) | fp=-2116480915/11746 | fp=-2116480915/11746 | fp=-256584047/5616 | ПРОВАЛ |
| 2-й | fp=1256670375/11746 | fp=1256670375/11746 | fp=-1178400053/5616 | ПРОВАЛ |
| 3-й | fp=-1310383518/11746 | fp=-1310383518/11746 | fp=549513350/5616 | ПРОВАЛ |

Одинаковый отпечаток у «По конкурентам» и «По метрикам» = дефект «подсветка меняется,
содержимое — нет». Значения различаются между прогонами, потому что менялись данные панели;
признак дефекта — РАВЕНСТВО отпечатков внутри одного прогона.

После фикса (интерфейс v-o0onrj) три режима дают три разных отпечатка, например:
По конкурентам fpВИДИМ=-1337357087/26890 · По метрикам 205435506/26828 · По источникам 602260455/5616.

## Почему прошлый «правильный» тест проходил

Сравнение по скрытому тексту (textContent с учётом display:none) давало разные значения
даже при одинаковом видимом экране. Поэтому в отчёт выводятся оба отпечатка:
fpВИДИМ (авторитетный) и fpВЕСЬ (контраст). Вердикт — по fpВИДИМ.

## Побочные находки того же периода

- Фильтр «любой радиус» в блоке конкурентов не менял строки (обработчик отсутствовал) — после фикса работает: 403→288.
- Ошибка самого теста на сортировке: заголовок после клика меняется на «ПРОЕКТ ↓», и поиск по тексту
  не находил узел. Исправлено: таблица и столбец ищутся по индексу, DOM запрашивается заново.
- Кнопки «Собрать данные сейчас» и «Сформировать отчёт за неделю»: подтверждение выводилось во
  всплывашке ВНЕ #view, поэтому тест не видел эффекта. После правки панели плашка выводится внутри
  раздела, и сценарий проверяется явно (шаг actions.*).
