# Три макета дизайна панели (dashboard/mock-design)

Это **макеты для выбора оформления**, а не рабочая панель. Рабочая панель живёт отдельно
(`serve.mjs` + `public/`) и этими файлами не затрагивается.

## Что внутри

| Файл | Вариант | Настроение |
|---|---|---|
| `variant-1-pult.html` | **1. «Пульт»** | Тёмный и плотный: максимум данных на экране, минимум движения, цвет только по смыслу |
| `variant-2-kabinet.html` | **2. «Кабинет»** | Светлый и воздушный: крупные заголовки и цифры, мягкие тени, плавные появления |
| `variant-3-glass.html` | **3. «Стекло»** | Тёмный премиум: градиентные пятна, полупрозрачные панели, микроанимации |
| `index.html` | витрина | Ссылки на три варианта, описание в одну строку и мини-превью |

**Структура у всех трёх одинаковая** — левое меню, шапка с рабочим пространством и кнопкой
«+ Создать», шесть KPI, две карточки и таблица очереди работ. Отличается только оформление,
поэтому варианты можно честно сравнивать. Данные вымышленные.

Структуру рисует один файл `mock.js`, оформление — `mock-common.css` (каркас)
плюс `theme-1-pult.css`, `theme-2-kabinet.css`, `theme-3-glass.css` (темы).

## Как посмотреть

Откройте `index.html` двойным щелчком — оттуда перейдите в любой вариант. Всё работает
локально по `file://`: шрифты Inter и JetBrains Mono берутся из `public/fonts`,
интернет не нужен.

## Чем варианты отличаются по делу

| | Вариант 1 «Пульт» | Вариант 2 «Кабинет» | Вариант 3 «Стекло» |
|---|---|---|---|
| Фон | `#0a0a0a`, поверхности `#1a1a1a`/`#222` | `#f7f7f8`, поверхности белые | `#08080c` с пятнами `#7553ff`→`#4fc1ff` |
| Радиусы | 10–14 px | 16–24 px | 20–28 px |
| Тени | почти нет | мягкие | светящиеся границы |
| Движение | нет, только подсветка наведения | плавное появление карточек | микроанимации, свечение цифр, дрейф пятен |
| Плотность | высокая: 6 KPI и таблица на одном экране | средняя, много воздуха | средняя, акцент на эффект |

## Рекомендация

- **Вариант 1 «Пульт» — для панели оператора.** За ней вы работаете каждый день: важнее
  плотность данных, спокойный фон и отсутствие отвлекающих эффектов.
- **Вариант 2 «Кабинет» — для личного кабинета клиента.** Светлый, понятный, не пугает
  человека, который зашёл посмотреть отчёт; хорошо показывает сервис на встрече.
- **Вариант 3 «Стекло» — для презентаций и обложек.** Запоминается, но при долгой работе
  градиенты и стекло утомляют.

Итого предлагаемый вариант: **«Пульт» для оператора + «Кабинет» для клиента**, «Стекло»
держим как витрину.
