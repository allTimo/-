Три варианта дизайна панели

Одинаковая структура (левое меню, шапка, шесть KPI, карточки, таблица очереди) — три разных оформления. Данные вымышленные: это макеты, а не рабочая панель.
Все три открываются локально, шрифты Inter и JetBrains Mono берутся из public/fonts — интернет не нужен.
Вариант 1. «Пульт»
Тёмный и плотный: максимум данных на экране, минимум движения, цвет только по смыслу.
Для вас и операторов сервиса — ежедневная работа по 8 часов.
рекомендуем для панели оператора
Вариант 2. «Кабинет»
Светлый и воздушный: крупные заголовки и цифры, мягкие тени, плавные появления карточек.
Для личного кабинета клиента, показов и продаж.
рекомендуем для кабинета клиента
Вариант 3. «Стекло»
Тёмный премиум: градиентные пятна, полупрозрачные панели, мягкое свечение цифр и микроанимации.
Для вау-эффекта и презентаций. При долгой работе утомляет.
риск: усталость при долгой работе
Рекомендация: вариант 1 для панели оператора (плотность и спокойный фон важнее эффектов) + вариант 2 для кабинета клиента (светлый и понятный, хорошо продаёт). Вариант 3 — для презентаций и обложек, но не как ежедневный рабочий интерфейс.
