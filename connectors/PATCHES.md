# Локальные патчи коннектора (Циан/Авито) — чтобы обновление клона их не потеряло

Задача T72. Клон живёт в `marketing-agents\connectors\ru-marketplace-mcp` и обновляется **tarball'ом**
(git в системе нет), поэтому любые правки внутри клона надо уметь повторить после обновления.
Ниже — что именно менялось, зачем, и как проверить.

## Задача: искать внутри конкретного ЖК

**Факт 1 (по коду клона).** У `cian_search` нет входного фильтра по новостройке: строка `newbuilding`
встречается только в моделях ВЫВОДА (`models_output.py`, `newbuilding_name`) и в тестах, входных параметров
нет. `cian_card` принимает только `offer_id_or_url`.

**Факт 2 (живой эксперимент, 01.11.2026).** Я добавил в запрос фильтр по ЖК и сравнил выдачу:

`@text
без фильтра                      total_count = 56198   в первой странице 19 разных ЖК
newbuilding_id: terms [1]        total_count = 56198   тот же состав
newbuilding:    terms [1]        total_count = 56198   тот же состав
`@

Вывод: **сервер Циан молча игнорирует фильтр по новостройке** — ни ошибки, ни сужения выдачи.
Выдумывать «правильный ключ» дальше смысла нет: перебраны оба очевидных варианта, поведение одинаковое.

## Что сделано вместо этого

### 1) Фильтр по ЖК в обёртке — РАБОТАЕТ И НЕ ТРЕБУЕТ ПАТЧА КЛОНА

`marketing-agents\connectors\run-connector.mjs` умеет `--newbuilding "<подстрока названия>"` и `--pages N`
(1–5): скачивает N страниц обычного поиска, оставляет только строки, у которых название ЖК, заголовок или адрес
содержат подстроку. Возвращает то же JSON-поле `payload`, но с полями `mode`, `filter`, `scanned`,
`matched`, `per_page_items` и массивом `items` только по этому ЖК.

Проверено живым вызовом:

`@text
node run-connector.mjs --tool cian_search --args-file out\cian_search.args.json \
     --newbuilding "Клубный дом ОПУС" --pages 2
  mode=newbuilding-filter (client side: Cian ignores a server-side filter)
  scanned=56  matched=3  pages=56/56 (28+28)
  100 455 970 ₽ | 2к | Клубный дом ОПУС | Москва, Дербеневская набережная, 5
  196 271 600 ₽ | 3к | Клубный дом ОПУС | Москва, Дербеневская набережная, 5
  262 146 440 ₽ | 4к | Клубный дом ОПУС | Москва, Дербеневская набережная, 5
`@

Важно: это фильтрация **скачанных** страниц (в данном случае 56 лотов из 56 198 по Москве), а не поиск по всему
городу. Для «перебирать 17 тысяч невежливо» этого достаточно: обёртка возвращает только лоты нужного ЖК.
Если понадобится глубже — увеличивайте `--pages` (до 5) или сужайте поиск ценой/комнатами.

### 2) Патч клона (экспериментальный, сейчас ничего не фильтрует)

В `packages\cian-connector\src\cian_connector\server.py` добавлены два входных параметра
(`newbuilding_id` и `extra_query`), чтобы можно было проверять ключи без перепатчивания:

1. сигнатура `_build_json_query`: после `page: int,` добавлено
   `newbuilding_id: str | None = None, extra_query: dict[str, Any] | None = None,`;
2. в конце `_build_json_query`, перед `return query`:
   `@python
   if newbuilding_id is not None:
       query["newbuilding"] = {"type": "terms", "value": [int(newbuilding_id)]}
   if extra_query:
       query.update(extra_query)
   `@
3. параметры инструмента `cian_search` добавлены в конец сигнатуры (перед `) -> CianSearchResponse:`);
4. в вызове `_build_json_query(...)` добавлены `newbuilding_id=newbuilding_id` и `extra_query=extra_query`.

Как проверить, что патч на месте: `@powershell
uv run --frozen --directory marketing-agents\connectors\ru-marketplace-mcp marketplace-mcp doctor
`@ (сервер поднимется; синтаксис проверен `python -c "import ast..."` -> OK).

После обновления клона (повторное скачивание tarball'а) патч теряется — **это не страшно**: основной фильтр живёт
в обёртке и работает на непатченном клоне. Если эксперимент с ключами понадобится снова, повторите 4 правки выше.

## Заодно зафиксированы грабли (для T71/T70)

* `cian_card(offer_id_or_url=...)` — единственный аргумент; `offer_id`/`id`/`url` не принимаются.
  `price_history` приходит как `[{"changed_at": ISO, "price_rub": N}]`, **от новых к старым**.
* `rooms=[0]` — ошибка валидации: студия в Циане это код **9** (`rooms=[9]`), 0 не принимается.
  Коды: 1–6 обычные, 7 свободная планировка, 9 студия.
* `region` — строка (`"1"`), не число.
* Обходной путь data-engine (T71: offer_id со страницы проекта + `cian_card`) полностью совместим с этой
  обёрткой и по-прежнему актуален как самый точный способ.
